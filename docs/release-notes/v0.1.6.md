# TM Publisher 0.1.6

[English](#english) · [Türkçe](#türkçe)

## English

A maintenance release: the way the program reads and writes its database changed inside. Nothing you see changes, and your
data stays as it is.

### What changed since 0.1.5

- **Storage through EF Core.** Every store (accounts, posts, schedules, settings and the rest) now goes through EF Core
  instead of hand-written SQL. The schema and every stored value keep the same form; encryption, backup/restore and the
  keyring vault are unchanged.
- **Your 0.1.5 database opens unchanged.** A test opens a database written by 0.1.5 and checks every value; new writes match
  the old rows byte for byte. Another test runs the published program with `--run-due` on a 0.1.5 database.
- A repository rule blocks hand-written SQL in the program from now on.

### Update

Quit TM Publisher, replace the program file with the new one and start it. No other step is needed.

## Türkçe

Bakım sürümü: programın veritabanını okuma ve yazma yolu içeride değişti. Ekranda bir şey değişmez, verin olduğu gibi kalır.

### 0.1.5'ten beri değişenler

- **Kayıt EF Core ile.** Bütün kayıtlar (hesaplar, paylaşımlar, zamanlamalar, ayarlar ve diğerleri) artık elle yazılmış SQL
  yerine EF Core üzerinden gider. Şema ve kayıtlı her değer aynı biçimde kalır; şifreleme, yedekleme/geri yükleme ve anahtar
  kasası değişmedi.
- **0.1.5 veritabanın değişmeden açılır.** Bir test, 0.1.5'in yazdığı veritabanını açıp her değeri denetler; yeni yazılanlar
  eski satırlarla bayt bayt aynıdır. Başka bir test, yayımlanan programı 0.1.5 veritabanında `--run-due` ile çalıştırır.
- Depo kuralı bundan sonra programda elle yazılmış SQL'e izin vermez.

### Güncelleme

TM Publisher'ı kapat, program dosyasını yenisiyle değiştir ve başlat. Başka adım gerekmez.
