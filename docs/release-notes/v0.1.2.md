# TM Publisher 0.1.2

[English](#english) · [Türkçe](#türkçe)

## English

A lighter release for the tray. TM Publisher waits in the tray all day, so it should take as little memory and processor time
there as possible. Nothing about your data changes: install it over 0.1.1 as described in the README (**Update**); your
accounts, groups and posts stay.

### What changed

- **Less memory in the tray.** Closing the window really closes it now, instead of only hiding it. Opening TM Publisher from
  the tray (or starting it again) makes a new window; an unfinished post and the page you were on are still there.
- **Started with the computer, no window is made at all** until you open it, and the pages (calendar, history, tags, waiting
  posts and the others) are prepared only the first time you open them.
- **The program draws with the processor, not the graphics card.** The graphics card driver used to be loaded into the program
  at start-up and stayed there all day, also in the tray. If drawing feels slow on a very large screen, start the program with
  `--gpu`, or set the environment variable `TMPUBLISHER_GPU=1` (it also reaches the "start with my computer" entry).
- When the program goes to the tray, the log file gets one line with its memory use (helpful if you report a problem).
- Linux: closing the window still minimizes it (a tray is not guaranteed on every Linux desktop), so the window is kept there;
  drawing with the processor applies on Linux too.

### Measured on Windows 11

Release files, an empty data folder, a computer with an NVIDIA graphics card. "Task Manager" is the **Memory** column in Task
Manager (private working set); "working set" also counts shared system files the program has open; "private" is all memory
only this program owns. The processor use stayed at 0–0.2 % of one core in every case.

| | 0.1.1 | 0.1.2 |
|---|---|---|
| In the tray, 60 s after starting with the computer: Task Manager / working set / private | 53 / 181 / 119 MiB | 35 / 113 / 39 MiB |
| Window open on the first page | 48 / 175 / 115 MiB | 39 / 137 / 43 MiB |
| Window opened and closed to the tray again, 60 s later | 49 / 177 / 116 MiB | 33 / 133 / 37 MiB |
| Threads in the tray | 61 | 13 |

On Linux (Raspberry Pi) the numbers have not been measured yet.

### Known limits

- **TikTok:** videos go to your TikTok inbox as drafts and you finish them in the TikTok app; the optional direct post is
  always private (only you can see it) and needs a private TikTok account. TikTok's audit does not accept tools that upload
  to your own account, so public direct posting is not possible.
- **Pinterest:** with Trial access, pins are visible only to you. Standard access needs Pinterest's review of your app.
  Apps created after 14 September 2026 may need a business account.
- **Instagram:** videos (Reels) only; Instagram takes photos only from a public web address.
- **Threads:** text only; photos and videos must come from a public web address.
- **LinkedIn:** the token lasts 60 days; connect again when reminded.
- **X** is paid per use (about $0.015 per post, $0.20 with a link, $0.005 per read).
- The release files are not code-signed: Windows SmartScreen asks once ("More info" → "Run anyway").
- No message or comment reading, no e-mail.

## Türkçe

Tepsi için daha hafif bir sürüm. TM Publisher bütün gün tepside bekler; orada olabildiğince az bellek ve işlemci kullanmalı.
Verilerinizde bir şey değişmez: README'deki **Güncelleme** adımlarıyla 0.1.1'in üzerine kurun; hesaplarınız, gruplarınız ve
gönderileriniz yerinde kalır.

### Değişenler

- **Tepside daha az bellek.** Pencereyi kapatmak artık onu yalnız gizlemiyor, gerçekten kapatıyor. TM Publisher'ı tepsiden
  açınca (ya da yeniden başlatınca) yeni bir pencere açılır; yarım kalan gönderiniz ve bulunduğunuz sayfa yerinde durur.
- **Bilgisayarla birlikte başlayınca** siz açana kadar hiç pencere yapılmıyor; sayfalar (takvim, geçmiş, etiketler, bekleyen
  gönderiler ve diğerleri) yalnız ilk açtığınızda hazırlanıyor.
- **Program ekran kartıyla değil işlemciyle çiziyor.** Ekran kartı sürücüsü açılışta programa yükleniyor ve tepside de bütün gün
  orada kalıyordu. Çok büyük bir ekranda çizim yavaş gelirse programı `--gpu` ile başlatın ya da `TMPUBLISHER_GPU=1` ortam
  değişkenini tanımlayın ("bilgisayarımla birlikte başlasın" kaydına da ulaşır).
- Program tepsiye geçince günlük dosyasına bellek kullanımını gösteren bir satır yazılıyor (bir sorun bildirirken işe yarar).
- Linux: pencereyi kapatmak yine küçültüyor (her Linux masaüstünde tepsi bulunmayabilir), pencere orada kalıyor; işlemciyle
  çizim Linux'ta da geçerli.

### Windows 11'de ölçülenler

Sürüm dosyaları, boş bir veri klasörü, NVIDIA ekran kartlı bir bilgisayar. "Görev Yöneticisi", Görev Yöneticisi'ndeki **Bellek**
sütunudur (özel çalışma kümesi); "çalışma kümesi" programın açtığı ortak sistem dosyalarını da sayar; "özel" yalnız bu programın
sahip olduğu belleğin tamamıdır. İşlemci kullanımı her durumda tek çekirdeğin %0–0,2'sinde kaldı.

| Pencere açık, ilk sayfada | 48 / 175 / 115 MiB | 39 / 137 / 43 MiB |

Linux'ta (Raspberry Pi) sayılar henüz ölçülmedi.

### Bilinen kısıtlar

- **TikTok:** videolar TikTok gelen kutunuza taslak olarak gider, TikTok uygulamasında tamamlarsınız; isteğe bağlı doğrudan
  paylaşım her zaman gizlidir (yalnız siz görürsünüz) ve gizli bir TikTok hesabı ister. TikTok denetimi kendi hesabına
  yükleyen araçları kabul etmediği için herkese açık doğrudan paylaşım mümkün değil.
- **Pinterest:** deneme (Trial) erişiminde pinler yalnız size görünür. Standart erişim için Pinterest'in uygulamanızı
  incelemesi gerekir. 14 Eylül 2026'dan sonra açılan uygulamalar işletme hesabı isteyebilir.
- **Instagram:** yalnız video (Reels); Instagram fotoğrafı yalnız herkese açık bir web adresinden alır.
- **Threads:** yalnız metin; fotoğraf ve video herkese açık bir web adresinden gelmeli.
- **LinkedIn:** anahtar 60 gün sürer; hatırlatılınca yeniden bağlayın.
- **X** kullandıkça ücretlidir (gönderi başına yaklaşık 0,015 $, bağlantılı 0,20 $, okuma başına 0,005 $).
- Sürüm dosyaları kod imzalı değil: Windows SmartScreen bir kez sorar ("Ek bilgi" → "Yine de çalıştır").
- Mesaj ya da yorum okuma yok, e-posta yok.
