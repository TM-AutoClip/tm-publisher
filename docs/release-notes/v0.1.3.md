# TM Publisher 0.1.3

[English](#english) · [Türkçe](#türkçe)

## English

TM Publisher is now two programs: a small **background scheduler** that runs all the time and sends your posts, and the
**window**, which runs only while you have it open. The scheduler is compiled to native code and has no window library, so
waiting for the next post takes a few megabytes instead of a hundred. Your data does not change: the same encrypted database and
the same key. Follow the README (**Update**); coming from 0.1.2, quit it from its tray first.

### What changed

- **Background scheduler** (`TMPublisherScheduler.exe` on Windows, `tm-publisher-scheduler` on Linux). It starts with the
  computer (the "start with my computer" entry now points to it) and whenever you open the window. One timer to the next post,
  no polling; it reads the schedule again when the window saves something, after the computer wakes from sleep, when the clock
  changes, and every 15 minutes as a safety net. The 5-minute grace for late posts stays.
- **The window really ends when you close it**, on Windows and on Linux. If a page has unsaved input, the first close asks
  you to close again.
- **Never twice:** only one scheduler runs per data folder (a lock file), and the scheduler does not start while an old
  0.1.0–0.1.2 TM Publisher runs on the same folder. Every send, also **Send now** from the window, first claims the post in the
  database; a post that another process has already claimed is not sent. Token refreshes of one account are locked across
  processes.
- **Master password:** the scheduler cannot ask for it. After the computer starts, open the window once and unlock it; the
  window hands the key to the scheduler over a local channel that only your user can open (never on a command line, in the
  environment, in a file or in a log). Until then nothing is sent and Settings shows "Waiting for the master password".
- **Notifications** in the bottom-right corner also appear when the window is closed: the scheduler starts a short-lived
  copy of the window program that shows them and ends a few seconds after the last one closes. When the window is open, it
  shows them itself.
- **Windows tray icon** now belongs to the scheduler: click to open the window; right-click for Open, Pause / Resume scheduling and
  Quit. **Linux has no tray icon**; Settings → **Background scheduler** shows the state on both systems and can start, stop,
  pause and resume it.
- **Smaller downloads.** The window program is trimmed (45 MB instead of 107 MB on Windows). The database layer is plain SQLite
  instead of Entity Framework Core; the database file is exactly the same.
- Texts you write are stored in Unicode NFC form (the scheduler runs without culture data to stay small, so the window
  normalizes the text before saving).
- The log of each program has its own file per day: `tmpublisher-…` (window), `tmpublisher-scheduler-…`,
  `tmpublisher-notify-…`. A minute after start the scheduler writes one line with its memory use.

### Known limits

- **linux-x64 scheduler:** Native AOT for Linux has to be built on a Linux machine of the same architecture, and this release
  was built on Windows and a Raspberry Pi. The x64 scheduler is a trimmed, precompiled single file instead and uses about
  twice the memory of the native one (measured above on arm64; not measured on x64). It works the same.
- **Master password** (always the case on Linux without a keyring): open the window once after each start of the computer,
  otherwise nothing is sent.
- **No tray icon on Linux.** Use the window's Settings → Background scheduler.
- **Windows zip is a folder** with `TMPublisher.exe`, `TMPublisherScheduler.exe` and `sqlite3mc.dll`. The scheduler is native
  code and the SQLite build with encryption that it uses comes only as a separate library, so it has to sit next to it; keep
  the three files together. The Linux archives have the same layout (`libsqlite3mc.so`).
- Everything from 0.1.2 still applies: TikTok drafts or private posts only, Pinterest Trial pins visible only to you,
  Instagram videos only, Threads text only, LinkedIn tokens last 60 days, X is paid per use, the files are not code-signed
  (SmartScreen asks once, also for the scheduler), no message or comment reading.

## Türkçe

TM Publisher artık iki program: sürekli çalışıp gönderilerinizi yollayan küçük bir **arka plan zamanlayıcısı** ve yalnız siz
açıkken çalışan **pencere**. Zamanlayıcı doğrudan makine koduna derlenir ve pencere kitaplığı içermez; sıradaki gönderiyi
beklemek yüz yerine birkaç megabayt tutar. Verileriniz değişmez: aynı şifreli veritabanı, aynı anahtar. README'deki
**Güncelleme** adımlarını izleyin; 0.1.2'den geliyorsanız önce onu tepsisinden kapatın.

### Değişenler

- **Arka plan zamanlayıcısı** (Windows'ta `TMPublisherScheduler.exe`, Linux'ta `tm-publisher-scheduler`). Bilgisayarla
  birlikte (bilgisayarla başlatma kaydı artık onu gösteriyor) ve pencereyi her açtığınızda başlar. Sıradaki gönderiye tek
  zamanlayıcı, sürekli yoklama yok; pencere bir şey kaydedince, bilgisayar uykudan uyanınca, saat değişince ve güvenlik için 15
  dakikada bir zamanlamayı yeniden okur. Geciken gönderiler için 5 dakikalık pay duruyor.
- **Pencereyi kapatınca program gerçekten kapanır**, Windows'ta da Linux'ta da. Bir sayfada kaydedilmemiş giriş varsa ilk
  kapatmada yeniden kapatmanız istenir.
- **Asla iki kez:** her veri klasörü için tek zamanlayıcı çalışır (kilit dosyası); aynı klasörde eski bir 0.1.0–0.1.2 TM
  Publisher çalışırken zamanlayıcı başlamaz. Her gönderim, penceredeki **Şimdi gönder** de, önce gönderiyi veritabanında üstüne
  alır; başka bir sürecin üstüne aldığı gönderi gönderilmez. Bir hesabın anahtar yenilemesi süreçler arasında kilitlidir.
- **Ana parola:** zamanlayıcı parolayı soramaz. Bilgisayar açıldıktan sonra pencereyi bir kez açıp kilidi açın; pencere
  anahtarı zamanlayıcıya yalnız sizin kullanıcınızın açabildiği yerel bir kanaldan verir (komut satırında, ortam
  değişkeninde, dosyada ya da günlükte asla yer almaz). O zamana kadar hiçbir şey gönderilmez, Ayarlar "Ana parola bekleniyor"
  gösterir.
- Sağ alttaki **bildirimler** pencere kapalıyken de görünür: zamanlayıcı pencere programının kısa ömürlü bir kopyasını
  başlatır, o bildirimleri gösterir ve sonuncusu kapandıktan birkaç saniye sonra kapanır. Pencere açıksa bildirimleri kendisi
  gösterir.
- **Windows tepsi simgesi** artık zamanlayıcının: tıklayınca pencere açılır; sağ tık menüsünde Aç, Zamanlamayı duraklat / sürdür
  ve Çıkış var. **Linux'ta tepsi simgesi yok**; iki sistemde de Ayarlar → **Arka plan zamanlayıcısı** durumu gösterir,
  başlatır, durdurur, duraklatır ve sürdürür.
- **Daha küçük indirmeler.** Pencere programı kırpıldı (Windows'ta 107 MB yerine 45 MB). Veritabanı katmanı Entity Framework
  Core yerine düz SQLite; veritabanı dosyası tamamen aynı.
- Yazdığınız metinler Unicode NFC biçiminde kaydedilir (zamanlayıcı küçük kalmak için kültür verisi olmadan çalışır; metni
  kaydetmeden önce pencere düzenler).
- Her programın günlüğü gün başına kendi dosyasında: `tmpublisher-…` (pencere), `tmpublisher-scheduler-…`,
  `tmpublisher-notify-…`. Zamanlayıcı başladıktan bir dakika sonra bellek kullanımını gösteren bir satır yazar.

### Bilinen kısıtlar

- **linux-x64 zamanlayıcısı:** Linux için Native AOT aynı mimaride bir Linux makinesinde derlenmeli; bu sürüm Windows'ta ve bir
  Raspberry Pi'de derlendi. x64 zamanlayıcısı onun yerine kırpılmış, önceden derlenmiş tek bir dosya; aynı işi yapar, yerel
  derlemenin yaklaşık iki katı bellek kullanır (yukarıda arm64'te ölçüldü; x64'te ölçülmedi).
- **Ana parola** (Linux'ta anahtarlık yoksa her zaman): bilgisayarın her açılışından sonra pencereyi bir kez açın, yoksa hiçbir
  şey gönderilmez.
- **Linux'ta tepsi simgesi yok.** Penceredeki Ayarlar → Arka plan zamanlayıcısı'nı kullanın.
- **Windows zip'i bir klasör:** `TMPublisher.exe`, `TMPublisherScheduler.exe` ve `sqlite3mc.dll`. Zamanlayıcı makine kodudur ve
  kullandığı şifreli SQLite yalnız ayrı bir kitaplık olarak geliyor; bu yüzden yanında durmalı. Üç dosyayı birlikte tutun. Linux
  arşivleri de aynı düzende (`libsqlite3mc.so`).
- 0.1.2'deki her şey geçerli: TikTok'ta yalnız taslak ya da gizli paylaşım, Pinterest deneme erişiminde pinler yalnız size
  görünür, Instagram'da yalnız video, Threads'te yalnız metin, LinkedIn anahtarı 60 gün, X kullandıkça ücretli, dosyalar kod
  imzalı değil (SmartScreen bir kez, zamanlayıcı için de sorar), mesaj ya da yorum okuma yok.
