# TM Publisher 0.1.7

[English](#english) · [Türkçe](#türkçe)

## English

TM Publisher now tells you when a new version is out. Your data does not change.

### What changed since 0.1.6

- **New version notice.** At every start the window asks GitHub, in the background, whether a newer TM Publisher is
  published. The window opens at once; it never waits for the answer. When a newer version exists, the bottom of the sidebar
  shows it with an **Open the download page** button.
- **Nothing is downloaded or installed by the program.** The button only opens the release page in your browser; you update
  by hand as before (see **Update** below).
- **Settings → Updates:** **Check now**, the result of the last check, and a switch to turn the check at start off.
- **Light on GitHub.** One request to `api.github.com` without an account; nothing about you or your posts is sent. The last
  answer is kept (`update-check.json` in the data folder) and its tag is sent again, so an unchanged answer does not count
  against GitHub's hourly limit. If GitHub asks to wait, the program waits quietly until the time GitHub names. Offline, the
  last known answer is used.
- The short runs that the system scheduler starts to send posts never check.

### Update

Quit TM Publisher, replace the program file with the new one and start it. No other step is needed.

## Türkçe

TM Publisher artık yeni bir sürüm çıktığında haber veriyor. Verin değişmez.

### 0.1.6'dan beri değişenler

- **Yeni sürüm bildirimi.** Pencere her açılışta, arka planda, GitHub'a daha yeni bir TM Publisher yayımlanıp
  yayımlanmadığını sorar. Pencere hemen açılır; cevabı hiç beklemez. Yeni sürüm varsa kenar çubuğunun altında
  **İndirme sayfasını aç** düğmesiyle gösterilir.
- **Program hiçbir şey indirmez ya da kurmaz.** Düğme yalnız sürüm sayfasını tarayıcında açar; güncellemeyi eskisi gibi elle
  yaparsın (aşağıdaki **Güncelleme**).
- **Ayarlar → Güncellemeler:** **Şimdi denetle**, son denetimin sonucu ve açılıştaki denetimi kapatan bir anahtar.
- **GitHub'ı yormaz.** `api.github.com`'a hesapsız tek istek; seninle ya da paylaşımlarınla ilgili hiçbir şey gönderilmez. Son
  cevap saklanır (veri klasöründe `update-check.json`) ve etiketi bir sonraki istekte gönderilir; değişmeyen cevap GitHub'ın
  saatlik sınırından düşmez. GitHub beklemeyi isterse program, GitHub'ın verdiği saate kadar sessizce bekler. İnternet yoksa
  bilinen son cevap kullanılır.
- Sistem zamanlayıcısının paylaşım göndermek için başlattığı kısa çalıştırmalar hiç denetlemez.

### Güncelleme

TM Publisher'ı kapat, program dosyasını yenisiyle değiştir ve başlat. Başka adım gerekmez.
